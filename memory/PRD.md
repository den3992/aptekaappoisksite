# PRD — АптекаА (агрегатор аптек)

## Original problem statement
MVP сайта-агрегатора аптек по образцу lekmos / 003ms / 009рф / aptekamos:
- Минималистичный современный дизайн в зелёно-белой палитре
- Стартовые города: Москва и Санкт-Петербург
- Поиск лекарств (без сложного каталога) с SEO
- Карточка препарата с интеграцией Яндекс.Карт и «облаками цен» (пины с ценами и наличием)
- Раздел «Для аптек» — простая FTP-выгрузка прайсов (xls, xlsx, dbf, csv)
- Юр. соответствие законам РФ. Юрлицо: ООО «Идеал-ФАРМ», ИНН 5050110424, г. Фрязино.
- Язык: русский.

## Architecture
- **Frontend**: React 19, Tailwind CSS, Framer Motion, React Router DOM. Все запросы идут на `${REACT_APP_BACKEND_URL}/api/*`.
- **Backend**: FastAPI + Motor (Async MongoDB). Все эндпоинты — под префиксом `/api`.
- **DB**: MongoDB. Сейчас активно: коллекция `voice_messages` (история диалогов с ассистентом).
- **AI ассистент**: Web Speech API (mic) → `/api/voice/chat` (FastAPI + Emergent LLM Key, gpt-4o-mini) → speechSynthesis (озвучивание).

- Контекст города (Москва / СПб)

### AI голосовой ассистент (✅ 2026-02-09)
- **Backend**: `POST /api/voice/chat` — gpt-4o-mini через Emergent LLM Key, мульти-сессионный диалог через `session_id`, история в MongoDB (`voice_messages`).
- **TTS**: `POST /api/voice/tts` — **Yandex SpeechKit** v1 (голос **Алёна**, эмоция `good`), формат `oggopus`, кэширование результатов в MongoDB по SHA-256 (текст+голос+эмоция+скорость) — повторные фразы возвращаются мгновенно без вызова API.
- **Frontend**: `VoiceAssistant.jsx` + `CallView.jsx` — два режима в одном виджете:
  - **Чат**: текстовый/голосовой ввод (push‑to‑talk), TTS озвучка ответов
  - **Беседа** (📞): беспрерывный голосовой диалог как по телефону:
    - Web Speech API в continuous-режиме (бесплатное распознавание в браузере)
    - VAD по таймауту 0.9 сек тишины → конец фразы → `/api/voice/chat` → `/api/voice/tts` → проигрывание Алёны
    - **Барж‑ин**: если пользователь начинает говорить во время ответа — аудио останавливается мгновенно
    - Анимированный пульсирующий аватар (слушаю / думаю / говорю)
    - Лента последних реплик, таймер разговора
    - Авто‑перезапуск SpeechRecognition (браузер останавливает её каждые ~60 сек)
- **Контекст бота**: 20 препаратов с ценами + 11 аптек партнёров (Москва/СПб) — `voice_data.py`.
- **Стоимость беседы**: STT бесплатный (браузер), TTS Алёна ~0.3 ₽/мин, LLM ~0.1 ₽/мин = **~0.4–0.5 ₽/мин** ⇒ 7000 минут/мес ≈ 2800–3500 ₽ (укладывается в бюджет 5000 ₽).
