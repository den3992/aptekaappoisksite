# Vertex whole-original pilot

This explicit provider supports one unchanged patient leaflet: Ginkgo Biloba,
current Russian registration 002790, capsules 80 mg, GTIN 04670033324402. The
reviewed binary SHA is pinned to eight pages and 755457 bytes. The other old-RU
variant on the same catalog card remains outside this scope.

The manual physical proof retains the full combined holder/manufacturer heading
and producer block on page 8. The website declaration is in a separate local
representative block on that page, with the same literal company and address.
It is never inserted into the producer block. The current GRLS row must still
explicitly name the finished-dosage-form manufacturer at the reviewed 62 lit.A
factory. No holder, packaging, QA, legal-form or generic-address fallback applies.

The provider requires the exact retained href, title and visible anchor text.
Archive validation rechecks its HTML sibling on every call and considers all
document-capable tags, MIME types, medical labels and download links. Unknown,
ambiguous, duplicated or changed instruction links remain blocked. Requests use
the existing bounded immutable cache, no redirects and a separate
`.source-stopped-vertex` marker.

Approval and leaflet revision dates remain unknown. The 2023 expert-report stamp
and the current GRLS normative-document entry are retained as separate facts.
All eight physical pages require visual project/version review; the binary
checker's first-page flag cannot replace it. This is whole-original delivery,
with no verified inline transcription or clinical calculations.

The retained source facts in the unit fixture are test input, not a published
wrapper or independent data approval. Code review, canonical-wrapper review,
native binary validation, actual-image runtime checks and fresh live overlap and
identity checks remain separate release steps.
