## 1. Что это за проект

**АптекаА** — бесплатный агрегатор поиска лекарств для Москвы и Санкт-Петербурга.

- **23 303** препарата в базе (из ЕСКЛП/ГРЛС)
- **12** партнёрских аптек (Москва + СПб)
- **Цены** сейчас **MOCKED** (нет реальной интеграции с прайсами)
- **Бизнес-модель**: SEO-агрегатор, монетизация позже (рекламные слоты партнёров)

**Ключевая ставка**: Yandex SEO. Главный архитектурный приём — **SSR для ботов** через nginx-уровневый bot-detection, при этом обычные пользователи получают React SPA.

**Голосовой ассистент** (микрофон на главной): Yandex SpeechKit STT/TTS + OpenAI `gpt-4o-mini` через Emergent LLM key. На проде fully работает (см. секцию 5).

## 3. Архитектура

### Стек
- **Frontend**: React 19 + Tailwind + Shadcn UI, hosted на nginx внутри Docker
- **Backend**: FastAPI + Motor (async MongoDB) + bcrypt + PyJWT, Python 3.11
- **Database**: MongoDB 7.0 в Docker
- **Edge**: nginx 1.27-alpine (SSL termination, rate limit, bot-detection, security headers)
- **Infra**: Yandex Cloud VM + Network Load Balancer (static IP)
- **Deploy**: Docker Compose, Let's Encrypt через certbot

### Сетевая схема
```
Browser/Bot
   ↓ HTTPS:443 / HTTP:80
Yandex NLB (111.88.158.153, static)
   ↓ TCP forward
VM (10.128.0.7 / 89.169.137.36)
   ↓
edge:nginx (Docker)
   ↓ proxy_pass
   ├── /api/*       → backend:8001 (FastAPI)
   ├── /robots.txt  → backend:8001/api/seo/robots.txt
   ├── /sitemap*.xml → backend:8001/api/seo/...
   └── /*           → frontend:80 (React SPA)
                      (если User-Agent = бот → rewrite на /api/seo/render)
```

### Docker-Compose сервисы
| Сервис | Образ | Порты | Логи |
|---|---|---|---|
| `edge` | nginx:1.27-alpine | 80, 443 | json-file, 50m×10 |
| `frontend` | свой build | (internal:80) | json-file, 10m×3 |
| `backend` | свой build (FastAPI) | (internal:8001) | json-file, 30m×5 |
| `imap_worker` | тот же что backend | — | json-file, 10m×5 |

## 4. Workflow деплоя

### Стандартный цикл
```bash
# На локалке (или через SSH прямо на VM)
ssh -i ~/.ssh/aptekaa_key ubuntu@89.169.137.36
cd ~/aptekaa

# 1. Внести изменения в код (или git pull)
# 2. Применить:
cd deploy

# Только backend изменения (Python код):
sudo docker compose up -d --force-recreate backend

# Только frontend (нужен rebuild, ~3-4 мин):
sudo docker compose build frontend
sudo docker compose up -d frontend

# Только nginx-конфиг:
sudo cp nginx/edge-ssl.conf nginx/active.conf
sudo chown root:root nginx/active.conf
sudo docker compose exec edge nginx -t  # validate
sudo docker compose exec edge nginx -s reload  # zero-downtime

# Полный рестарт:
sudo docker compose up -d
```

### .env handling
- `~/aptekaa/deploy/.env` — единственный источник правды для production
- ⚠️ **Никогда не коммитить** (`.gitignore` уже корректен)
- Структура — см. `~/aptekaa/deploy/.env.example` (если будет создан)
- При смене значений: backup → patch → `docker compose up -d <service>` (recreate, чтобы env подхватился)

### Hot reload
- **Backend**: НЕТ hot reload в проде. Каждое изменение Python = recreate контейнера
- **Frontend**: build-time bake. Любое изменение фронт-кода = full rebuild (~3-4 мин)
- **Nginx**: `nginx -s reload` zero-downtime

## 7. SEO архитектура (особенность)

**Ключевой архитектурный приём — не сломай.**

### Bot-detection в nginx
В `deploy/nginx/edge-ssl.conf` в `location /`:
```nginx
if ($http_user_agent ~* "(YandexBot|Yandex|Googlebot|bingbot|...)") {
    rewrite ^(.*)$ /api/seo/render?path=$1 last;
}
```
- **Обычные пользователи**: получают React SPA с `<div id="root">` и JS
- **Боты**: получают полностью отрендеренный HTML с тайтлом, мета, schema.org

### Schema.org markup
Бэкенд `seo.py:_render_*` функции генерируют:
- `Drug` (medical entity)
- `Product` с `AggregateOffer` (priceCurrency=RUB, lowPrice/highPrice/offerCount, areaServed)
- `FAQPage` (из LLM enrichment, у 890 препаратов)
- `DrugStrength` (10 мг/мл → strengthValue + strengthUnit)
- `activeIngredient` (МНН), `legalStatus` для narcotic, `priceCurrency` ЖНВЛП limit_price

### Тестировано
- Морфин (narcotic, Rx): Drug + Product + 12 offers 90-125₽ ✅
- Кетопрофен OTC (enriched): + FAQPage с 3 вопросами ✅

## 8. Безопасность (текущее состояние)

### Что настроено

#### Уровень сети
- **Yandex NLB** static IP `111.88.158.153`
- **Yandex Cloud Security Group**: открыты только 80/443/22 (последний — только с whitelisted IP пользователя; уточнить!)

#### TLS (SSL Labs **A+**)
- Let's Encrypt сертификат, auto-renewal через certbot
- TLS 1.2 + 1.3 only, ECDHE-only ciphers, Forward Secrecy robust
- HSTS `max-age=31536000; includeSubDomains; preload`
- ⚠️ **OCSP stapling не настроен** — Let's Encrypt с мая 2025 перестали включать OCSP responder URL в сертификаты

#### HTTP headers (securityheaders.com **A**, Mozilla Observatory **B+ 80/100**)
Всё в nginx — **единый источник** (FastAPI middleware удалён):
- `Strict-Transport-Security: max-age=31536000; includeSubDomains; preload`
- `X-Frame-Options: DENY`
- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy: camera=(), microphone=(self), geolocation=(self), interest-cohort=(), payment=()`
- `Cross-Origin-Opener-Policy: same-origin`
- `Cross-Origin-Resource-Policy: same-site`
- `Content-Security-Policy: ...` (на всех маршрутах)

**CSP содержит `'unsafe-inline'` + `'unsafe-eval'`** в `script-src` — это нужно для Yandex Maps. Без них карты не работают. **Из-за этого securityheaders capped на A, Mozilla на B+** — это реалистичный максимум с Я.Картами.

⚠️ **Cross-Origin-Embedder-Policy: require-corp** сознательно **НЕ добавлен** — сломает Я.Карты (они не отдают CORP-заголовки).

#### Rate limiting (nginx)
См. секцию 5.

#### Admin auth
- JWT (HS256, 8h TTL) — primary для UI
- Legacy X-Admin-Token header — для IMAP/CSV uploads
- bcrypt для паролей (`ADMIN_PASSWORD_HASH` в .env)
- `admin_audit_log` пишется при каждой попытке

#### Secrets hygiene

- `.gitleaks.toml` + `.gitleaksignore` в репо
- pre-commit hook (`.git/hooks/pre-commit`) — блокирует staged secrets

## 18. Стиль работы (рекомендации для нового агента)

1. **Не разворачивай локально**. Реальный код только на VM (`~/aptekaa/`). Локалка (`/app/`) пустая. Все правки → SSH + scp / inline Python.
2. **Не пуши workflow-файлы** без PAT с `workflow` scope. Проверь сначала: `git push origin main`.
3. **HANDOFF*.md содержат старые (мёртвые) секреты**. `.gitleaks.toml` уже их allowlist'ит. Не паникуй.
4. **`docker compose up -d <service>` recreate, не restart** — env-переменные подхватываются только при recreate.
5. **На проде нет hot reload**. Любая правка backend = `docker compose up -d --force-recreate backend`.
6. **Mongo `_id` исключай в проекциях** — `find({}, {_id:0, ...})`. ObjectId не сериализуется в JSON.
7. **Не парсить агрегаторы** (apteka.ru, eapteka.ru) — только сайты производителей.
8. **Для голосовых функций**: STT работает, TTS работает, **chat НЕ работает на проде**. Если нужно chat — переписать на прямой OpenAI key (1 час работы).
9. **Pre-commit hook gitleaks автоматически проверит** твои коммиты. Если найдёт fake secret — добавь fingerprint в `.gitleaksignore` или измени файл.
10. **Не показывай PAT и реальные secrets в ответах** — содержимое выводимое в чат может попасть в логи.
